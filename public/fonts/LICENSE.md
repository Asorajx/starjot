# Twemoji font

`Twemoji.Mozilla.ttf` is Mozilla's colour-font build of Twemoji, used for every emoji in Starjot
(see `src/frontend/app/styles.css`).

- Source: https://github.com/mozilla/twemoji-colr, release v0.7.0 (Twemoji 14, Unicode 14).
- Graphics: Twemoji, Copyright 2020 Twitter, Inc and other contributors, licensed under
  CC-BY 4.0: https://creativecommons.org/licenses/by/4.0/
  (https://github.com/twitter/twemoji, now maintained at https://github.com/jdecked/twemoji).
- Font build: Copyright Mozilla, licensed under the Apache License 2.0:
  https://www.apache.org/licenses/LICENSE-2.0

The file is used unchanged. Exported HTML files and canvas pictures that show emoji carry a copy
of it, so this attribution applies to them too.
