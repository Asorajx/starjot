# Starjot

Starjot is a browser-based workspace for notes and project work. It brings writing, visual ideas, and task organisation together in one application.

The current version stores workspace data locally in the browser.

## Overview

Starjot provides two spaces: Notespace for creating and organising notes, and Boardspace for managing project work. Users can write and format notes, develop ideas on a canvas, and view work as a list, board, or timeline.

## Goals

- Make it easy to capture and organise information
- Keep notes and project work in one workspace
- Support both written and visual thinking
- Provide different ways to view and manage work
- Make related information easier to find and connect
- Keep workspace data locally accessible

## Features

- Rich text notes with images, tables, links, and drawings
- Canvas notes for visual ideas
- Categories, starred notes, and search
- Note links and backlinks
- Import and export for supported formats
- Project summary, list, board, and timeline views
- Work items, sprints, and project members
- Reminders and an inbox
- Light and dark themes and appearance settings
- Local workspace storage
- Responsive layout

## Getting started

To run Starjot locally, clone or download the repository and follow the steps below. If you use the hosted website, no installation is needed.

Install Node.js and npm, then open a terminal in the project folder.

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local address shown in the terminal.

If PowerShell blocks npm, use `npm.cmd install` and `npm.cmd run dev` instead.
